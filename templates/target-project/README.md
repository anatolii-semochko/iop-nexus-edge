## Adding your own devices/processes/UI/commands

- `plugins/` - your own device types, process kinds, API command
  routes, and UI controls (private, not part of nexus-edge).
- `extra-res/` - the EdgeX device profiles/device-lists your plugins'
  devices need (`EXTRA_RES_DIR`).
- `migrations/` - this project's own Postgres seed data (applied by the
  `migrate-extra` service, after nexus-edge's own core migrations).

Full walkthrough, one section per extension point:
[`docs/CREATING_A_TARGET_PROJECT.md`](__NEXUS_EDGE_REPO_URL__/blob/main/docs/CREATING_A_TARGET_PROJECT.md)
(or, on the machine this project was generated on:
`__NEXUS_EDGE_SOURCE_PATH__/docs/CREATING_A_TARGET_PROJECT.md`).

## Makefile targets

`up` / `down` (platform only), `up-all` / `down-all` (platform + EdgeX),
`build`, `logs`, `ps`, `restart`, `sh SERVICE=<name>`. `up`/`up-all`/
`build` run `check-version` (nexus-edge version drift) and `check-ports`
(host-port collisions) first - both warn, neither blocks.
