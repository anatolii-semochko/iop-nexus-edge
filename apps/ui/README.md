# @nexus-edge/ui

Local React interface for the NexusEdge platform.

Based on the CoreUI Free React Admin Template (Vite + React + `@coreui/react`).
Template-specific documentation from the original vendor package is kept in
`VENDOR-TEMPLATE-README.md`, `ARCHITECTURE.md` and `DEVELOPMENT.md` for reference.
Vendor template license: see `THIRD-PARTY-LICENSE-CoreUI.txt` (MIT).

Application code added on top of the template is licensed under Apache-2.0,
same as the rest of the NexusEdge repository.
